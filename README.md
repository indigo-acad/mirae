# MIRAÉ · The Indigo Language Academy

Сайт школы: главная, вход и регистрация, личный кабинет, курс в виде пути, уроки, дополнительные упражнения и панель преподавателя.

Сайт статический, без сборки: обычные HTML, CSS и JS. Данные учеников, вход и назначения живут в Supabase (функции с проверкой логина и PIN). Любое изменение в файлах сразу попадает на сайт после публикации ветки.

## Дизайн

- Палитра школы: индиго `#0B1535` и `#1E2A56`, золото `#D4AF7C`, слоновая кость `#F8F7F2`, серебро `#C0C6D4`.
- Шрифты: Cormorant Garamond для заголовков, Inter для текста.
- Две среды. «Ночь»: страница и стеклянные карточки, светлый текст на индиго. «Бумага»: карточки с учебным материалом, тёмный текст на слоновой кости. Чтобы карточка стала стеклянной, достаточно класса `card glass`.
- Значки контурные, одного семейства: `KR.icon("book")`. Эмодзи из данных уроков показываются такими же значками (`KR.emo`).
- Движение отключается, если в системе включено «уменьшение движения». Фон на главной можно остановить кнопкой в углу.

## Языковые разделы

У школы два раздела: корейский и английский. Ученик видит раздел языка, по которому ему назначен хотя бы один материал; если назначены оба, в шапке появляется переключатель. Преподаватель видит оба раздела.

Раздел задаёт программу на странице курса, список упражнений, словарь, голос озвучки и оформление: свой акцентный цвет, орнамент и пейзаж в заголовке (корейский: пять вершин с луной, сосны и беседка; английский: холмы, Стоунхендж, дуб и церковь). Рисунки лежат в `img/`.

В английском разделе глава пути — это материал из каталога; пройденное ученик отмечает сам.

## Словарь и интервальное повторение

Страница «Слова» работает как Anki: новое слово показывается через минуту и через десять минут, потом через день, дальше интервал растёт. Оценки: «Снова», «Трудно», «Хорошо», «Легко».

Откуда берутся слова:

- из урока: слова блока «Слова» добавляются сами, когда ученик открывает урок;
- по выделению: ученик выделяет слово в тексте урока, видит перевод и нажимает «В словарь»;
- от преподавателя: в панели «Ученики» в карточке ученика есть «Словарь ученика»;
- вручную на странице «Слова».

Если слово у ученика уже есть и его добавляют ещё раз (или отмечают звёздочкой), интервал делится пополам и слово встаёт в очередь на сегодня.

Игры взяты из тренажёра группы 2724: карточки, выбор перевода на слух, слово в предложении, письмо, сборка слова из слогов, поиск пары. Ученик выбирает игры и меняет интервалы во вкладке «Настройки».

Чтобы словарь хранился в облаке и был виден преподавателю, выполните в Supabase файл `supabase/vocab.sql`. Без него словарь работает, но только на устройстве ученика.

## Перевод по выделению

Сначала перевод ищется в словах уроков и в словаре ученика (у корейских слов узнаётся основа: 지내지요 → 지내다). Если слова там нет, сайт обращается к переводчику из `TRANSLATE` в `js/config.js`:

- `"mymemory"`: бесплатный машинный перевод, выделенный текст отправляется на api.mymemory.translated.net (так сейчас);
- адрес своей функции: если подключите другой переводчик;
- `false`: только свои слова.

## Озвучка

Сайт выбирает лучший голос, который есть на устройстве, отдельно для корейского и английского. Ученик может выбрать голос и скорость на странице «Слова» → «Настройки». Самые живые встроенные голоса у браузера Microsoft Edge и у Safari на iPhone.

Облачный голос подключается через `TTS_URL` в `js/config.js`: это адрес функции, которая получает `{text, lang}` и возвращает звук. Пока он пуст, говорит голос устройства.

## Как включить регистрацию учеников

Сейчас учеников создаёт преподаватель. Чтобы ученики могли регистрироваться сами:

1. В Supabase откройте SQL Editor, вставьте содержимое `supabase/registration.sql` и нажмите Run. Запускать повторно безопасно.
2. Войдите на сайт как преподаватель, откройте «Ученики» и в карточке «Регистрация учеников» выберите режим:
   - **Закрыта**: как раньше, учеников создаёт только преподаватель.
   - **По коду школы**: ученик сам придумывает логин и PIN, но должен знать код. Код можно придумать кнопкой.
   - **Открыта**: зарегистрироваться может любой, у кого есть ссылка. Не больше 40 регистраций в сутки.
3. На странице входа появится вкладка «Регистрация». Новый ученик виден в списке с пометкой «новый», пока ему ничего не назначено.

Преподаватель может удалить ученика (вместе с прогрессом и назначениями) кнопкой «Удалить» в его карточке.

## Прохождение как история

Страница курса уже показывает программу как путь: пройденные главы, текущая, закрытые и будущие, золотая линия доходит до текущей главы.

Чтобы добавить главе сюжетную вставку, допишите уроку в `data/course.js` поле `scene`:

```js
{ no: 12, title: "-지요?", id: "l12-jiyo", scene: "Короткий текст сцены" }
```

Текст появится в карточке главы. Состояние ученика хранится в Supabase одним объектом; незнакомые ключи при сохранении не теряются, так что будущие данные сюжета (выборы, открытые сцены) можно класть рядом с `progress`.

## Помощник

В `js/config.js` есть переключатель `ASSISTANT`:

- `false`: выключен;
- `"teacher"`: кнопку и панель видит только преподаватель (так сейчас);
- `true`: видят все вошедшие ученики.

Сейчас это заглушка без ответов. Когда появится серверная часть, её адрес записывается в `ASSISTANT_URL`, а отправка вопроса дописывается в `KR.assistant.ask()` в `js/assistant.js`.
