# MIRAÉ · The Indigo Language Academy

Сайт школы: главная, вход и регистрация, личный кабинет, курс в виде пути, уроки, дополнительные упражнения и панель преподавателя.

Сайт статический, без сборки: обычные HTML, CSS и JS. Данные учеников, вход и назначения живут в Supabase (функции с проверкой логина и PIN). Любое изменение в файлах сразу попадает на сайт после публикации ветки.

## Урок: теория и отработка

Урок делится на две части с вкладками наверху:

- **«Теория»** — разминка, слова, грамматика, примеры. В конце кнопка «Отработать»;
- **«Отработка»** — упражнения с проверкой и задания «поговорить». Внизу «Хочешь ещё?» — доп. упражнения к уроку (или игры хангыля).

Часть раздела определяет `KR.part` в `js/common.js`: раздел, где все блоки — упражнения (`fill`, `choice`, `build`, `talk`), относится к отработке, остальные — к теории. Раздел может указать часть сам: `part: "theory"` или `part: "practice"`. Раздел `hw` («Домашнее задание» в данных хангыля и CLT) в уроке не показывается и в прогресс не входит: домашку задаёт преподаватель, этот раздел он может выбрать в «Задать домашку».

Урок открывается там, где остались незакрытые блоки; `?part=practice` открывает отработку, ссылка на раздел (`#grammar`) — нужную часть.

## Домашка

Домашку задаёт преподаватель каждому ученику: «Ученики» → карточка ученика → «Домашка» → «Задать домашку».

- **Что можно задать:** упражнения из отработки любого урока сайта (ученик делает их заново, со своими ответами, отдельно от урока), «Домашнее задание» из урока, тренажёры и тесты из каталога. Упражнение можно задать целиком или только отдельные задания из него: под упражнением — «выбрать отдельные», там у каждого вопроса (у «поговорить» — у каждой реплики) своя галочка; у упражнения тогда стоит отметка «частично» и подпись «выбрано 3 из 8». Ученик видит в домашке только отмеченные задания, баллы считаются из них. Так же и с тренажёрами (все материалы вида «Тренажёр», в том числе новые): у тренажёра в списке «Материалы» — «выбрать отдельные задания», там задания по группам (наборы слов и шаги пути, проверка по юнитам, Speaking, Essay, Listening, Reading, станции квеста, уроки программы), у группы своя галочка «все задания группы». Ученик открывает тренажёр из домашки только с выбранными заданиями: лишние вкладки спрятаны, сверху плашка «Домашка от преподавателя», прогресс этой домашки хранится отдельно от обычного прохождения, отчёт помечен «домашка». Как это устроено и что нужно новому тренажёру — в разделе «Отдельные задания тренажёра». По желанию — разделы теории: у ученика появится кнопка «Посмотреть теорию» и подсказка «Не помнишь, как это использовать? Загляни в теорию». Срок и комментарий — тоже по желанию.
- **Ученик** видит домашку в кабинете под словами: срок, сколько сделано, кнопки «Теория» и «Сделать». Домашка открывается отдельной страницей (`lesson.html?hw=<номер>`) только с заданными упражнениями. Упражнение засчитывается, когда его проверили (ошибки можно исправить и проверить ещё раз), тренажёр — когда из него отправлен отчёт «Отправить учителю» или ученик отметил его сам. Когда всё сделано, ученик нажимает «Сдать преподавателю»: баллы и ошибки уходят преподавателю, домашка исчезает из кабинета.
- **Преподаватель** видит сданную домашку сверху карточки: баллы, ответы ученика и верные ответы. «Проверено» с комментарием — ученик увидит комментарий в кабинете и закроет его кнопкой «Понятно». Заданную, но ещё не сданную домашку можно убрать.

Для домашки выполните в Supabase файл `supabase/homework.sql` (таблица `homework` и функции `teacher_hw_save`, `teacher_hw_list`, `teacher_hw_delete`, `teacher_hw_check`, `my_homework`, `hw_submit`, `hw_seen`). Пока файла нет, сайт работает как раньше: у ученика нет блока домашки, у преподавателя — подсказка, что выполнить. Заготовленный список `HOMEWORK` из `data/course.js` больше не используется. Отдельные задания хранятся в самом задании домашки (поле `i`: `{"<раздел>-<номер>": [номера заданий]}` рядом со списком упражнений `b`), новый SQL для них не нужен.

## Отдельные задания тренажёра

Код — в `js/bridge.js` (он уже подключён к каждому материалу через `tools/inject.py`), список заданий отдаёт сам тренажёр, поэтому `data/` и SQL трогать не нужно.

- **Список для преподавателя.** При «выбрать отдельные задания» панель открывает тренажёр в скрытой рамке с `?mirae-parts=…`. В этом режиме тренажёр ничего не отправляет и не сохраняет, а мост присылает панели список заданий.
- **Откуда список.** Если тренажёр объявил `window.MIRAE_PARTS = [{g: "группа", t: [{k: "ключ", n: "название"}]}]` — берётся он. Иначе мост собирает список сам: шаги пути слов (глобальный массив `STEPS` с `key`, `name`, `set`, как во всех тренажёрах слов) и вкладки (`nav button[data-tab]` с разделом `#tab-<имя>`). Поэтому новый тренажёр по тому же образцу работает сразу; если в нём нет ни шагов, ни вкладок, его можно задать только целиком.
- **Домашка.** Ссылка из домашки: `…/?hw=<номер>&only=<ключ,ключ>`. Тренажёр со своим `MIRAE_PARTS` сам оставляет выбранное до первой отрисовки: `MIRAE_PICK.keep(массив, (x, i) => ключ)`, для параллельных массивов `MIRAE_PICK.take(массив, номера)`, пустые вкладки — `MIRAE_PICK.tabs({вкладка: число})`. Если тренажёр этого не сделал, после загрузки мост сам оставит выбранные шаги `STEPS` и вкладки. Ключи localStorage тренажёра (кроме `kr_…` сайта) и его облачная запись (`load_progress`/`save_progress` со своим `p_site`) в домашке получают добавку `:hw<номер>`, так что домашка не трогает обычное прохождение. Отчёт «Отправить учителю» помечается «Домашка: выбранные задания».
- **Новый тренажёр с другим устройством заданий** (тесты, станции, темы эссе): после объявления массивов добавить блок «MIRAÉ: задания для домашки», как в `materials/english/en-ielts-band6-transport` или `materials/korean/ko-sago-quiz`, — `window.MIRAE_PARTS` и `if (window.MIRAE_PICK) MIRAE_PICK.keep(…)`.

## Тест на начало урока

Тест по словам в двух видах (страница `test.html`, код `js/wtest.js`), по образцу тестов «на уроке» из `materials/english/en-test-band9-class`:

- **С учителем** — вопросы по одному на экране, ответ сразу проверяется, «👀 Показать ответ», «Дальше», счёт ✅/❌ сверху. В конце — итог, таблица ошибок и «🔁 Повторить ошибки». Без таймера. Клавиши: 1–4 — вариант ответа, Enter — дальше;
- **Самостоятельно** — ответ сразу проверяется и не исправляется, по желанию таймер. Ответы сдвигают повторение слов ученика (как упражнения уроков).

Вопросы: слово → перевод (выбор), перевод → слово (выбор), вставь слово в предложение (видны первые буквы или первый слог), напиши слово по переводу.

**Форматы отработки** (преподаватель отмечает любые, они чередуются по словам; готовые наборы «Основа», «Полегче», «На слух», «Письмо», «Всё вперемешку»): перевод (выбор), слово по переводу (выбор), верно или неверно, найди пары (до 4 слов в одном задании), слово в предложение (выбор), вставь в предложение (написать), напиши слово, по первой букве (видна первая буква или слог и клеточки), собери слово из букв или слогов, на слух: выбери перевод, диктант на слух, скажи вслух (распознавание речи). Если формат на устройстве ученика не работает (нет озвучки или микрофона) или слову не подходит (нет примера), задание заменяется похожим письменным.

**Откуда слова и миксы.** Группы: «Новые слова» (добавлены за 1–30 дней), «Слова недели», «Пора повторить», «Сложные» (забывал, ошибки, звёздочка, возвращал учитель), «Все слова», «Слова урока». Можно отметить несколько — получится микс; готовые: «Новые + повторение», «Новые + слова недели», «Новые + сложные», «Новые + слова урока». В миксе задаётся доля первой группы (треть, половина, две трети) и «новое слово — дважды, в разных форматах». Из повторения сначала берутся трудные и давно ждущие слова. Новые слова разбросаны между повторением, второе появление нового — во второй половине. Порядок хранится в задании (`ord`), у слова метка группы `g` — в итоге теста ученик и преподаватель видят счёт по группам («новые: 5 из 6 · повторение: 7 из 9»).

Где собрать тест:

- **Преподаватель → карточка ученика → «Тест на начало урока».** Слова: «Слова недели» (ученик начинал их учить или повторял за 7 дней), «Пора повторить», «Все слова» ученика, «Слова урока» (уроки сайта с блоком «Слова»). Типы вопросов, число вопросов. «С учителем ↗» открывает тест в новой вкладке, «Дать самостоятельно» задаёт его домашкой (с таймером и сроком): ученик проходит тест со страницы домашки, баллы и ошибки приходят вместе с домашкой;
- **Урок → «Отработка» → «Тест по словам урока»:** ученик — «Проверить себя», преподаватель — ещё и «С учителем».

Тест в домашке — задание вида `{"wt": {...}}` в `supabase/homework.sql`: слова лежат в самом задании.

## Как ученик учит слова (для преподавателя)

В карточке ученика, в блоке «Словарь ученика» — «Как учит слова»: сколько новых слов начато и сколько повторений за 7 дней, сколько дней были занятия, последнее занятие, столбики по дням за 14 дней (новые слова и повторения, подсказка при наведении, таблица «По дням»), списки «Начал(а) учить за неделю» и «Повторил(а) старые за неделю», сколько слов не повторено вовремя.

Данные — журнал по дням, который ведёт `js/vocab.js` при каждом ответе на странице «Слова» (`kr_wlog:<ученик>`, 60 дней). Журнал уходит в облако вместе с прогрессом ученика (ключ `wl` в `save_progress`), новый SQL не нужен. Пока ученик не открывал обновлённый сайт, дни считаются по карточкам слов приблизительно.

## Результаты из тестов и игр

Тесты, тренажёры и игры из `materials/` — отдельные страницы со своим кодом. Раньше их результаты уходили только Telegram-боту, а на сайте не оставалось ничего. Теперь каждый материал подключает `js/bridge.js`. Мост работает, если ученик вошёл на сайт, и делает две вещи:

- **Отчёт «Отправить учителю».** Текст, который материал шлёт боту, сохраняется в записи ученика. Преподаватель видит его в панели «Ученики» в блоке «Отчёты из тестов и игр». Если Telegram недоступен или не ответил за 9 секунд, а сайт отчёт сохранил, ученик видит «отправлено». Telegram по-прежнему получает отчёт, когда работает.
- **Время занятий.** Мост считает, сколько раз материал открыт и сколько минут ученик в нём занимался (пока вкладка открыта и он что-то делает). Это блок «Занятия в материалах», там же отметки «пройдено», которые ученик ставит у английских материалов.

Всё хранится в обычной записи ученика (`save_progress`, ключи `mat` и `rep`), новый SQL не нужен. Ученик видит у назначенного материала значок «отчёт у преподавателя». Новый материал подключается командой `python3 tools/inject.py` из корня сайта.

## Дизайн

- Палитра школы: индиго `#0B1535` и `#1E2A56`, золото `#D4AF7C`, слоновая кость `#F8F7F2`, серебро `#C0C6D4`.
- Шрифты: Cormorant Garamond для заголовков, Inter для текста.
- Две среды. «Ночь»: страница и стеклянные карточки, светлый текст на индиго. «Бумага»: карточки с учебным материалом, тёмный текст на слоновой кости. Чтобы карточка стала стеклянной, достаточно класса `card glass`.
- Значки контурные, одного семейства: `KR.icon("book")`. Эмодзи из данных уроков показываются такими же значками (`KR.emo`).
- Движение отключается, если в системе включено «уменьшение движения». Фон на главной можно остановить кнопкой в углу.

## Языковые разделы

У школы два раздела: корейский и английский. Ученик видит раздел языка, по которому ему назначен хотя бы один материал; если назначены оба, в шапке появляется переключатель. Преподаватель видит оба раздела.

Раздел задаёт программу на странице курса, список упражнений, словарь, голос озвучки и оформление: свой акцентный цвет, орнамент и пейзаж в заголовке (корейский: башня Намсан на холме, горы, зал-ханок, сосны, луна и ветка сливы; английский: Биг-Бен, колесо обозрения, разводной мост, капелла, фонари и розы). Рисунки лежат в `img/`.

Шапка страницы курса сделана по макету: пейзаж `img/hero-ko.svg` / `img/hero-en.svg` (2000×300) идёт во всю ширину экрана, текст стоит слева над его низкой частью, ориентиры и луна справа. На телефоне текст стоит над пейзажем, а пейзаж сдвинут так, чтобы были видны горы и зал или колесо и мост. Ширина страницы курса растёт вместе с экраном (до 2200 px), поэтому на больших мониторах нет пустых полей по бокам. Рисунки рисует `tools/art.py` (`python3 tools/art.py` пишет их в `img/`).

## Словарь и интервальное повторение

Страница «Слова» работает как Anki: новое слово показывается через минуту и через десять минут, потом через день, дальше интервал растёт. Оценки: «Снова» (всегда через 1 минуту), «Трудно» (всегда дольше, чем «Снова»), «Хорошо», «Легко».

На странице два блока, один под другим:

- **«Новые слова»** — новые слова на сегодня (не больше «Новых слов в день» из настроек). Кнопка «Учить новые слова» показывает каждое слово целиком: перевод, пример, звук, картинку. «Запомнить» — слово уходит в отработку и вернётся через несколько минут; «Уже знаю» — сразу в повторения, с интервалом «Легко». В конце сайт предлагает закрепить разобранные слова в отработке;
- **«Отработка»** — упражнения (игры) по словам, которые уже в работе: «учу сейчас» и повторения на сегодня. Новых, ещё не разобранных слов в отработке нет.

Откуда берутся слова:

- из урока: когда ученик впервые открывает урок, сайт спрашивает «Добавить N слов урока в словарь?» («Не добавлять» / «Добавить»; галочка «Запомнить выбор для следующих уроков»). Поведение задаётся в «Слова» → «Настройки» → «Слова из уроков»: «Спрашивать» (по умолчанию), «Добавлять сами», «Не добавлять». Ответ по каждому уроку хранится вместе с настройками словаря и синхронизируется между устройствами. Передумать можно кнопкой под словами урока, а отдельные слова — отметить звёздочкой;
- по выделению: ученик выделяет слово в тексте урока, видит перевод и нажимает «В словарь»;
- от преподавателя: в панели «Ученики» в карточке ученика есть «Словарь ученика»;
- вручную на странице «Слова».
- из материалов (`materials/`): в материалах со словами (тренажёры слов, видео-уроки вроде Holiday House, тесты по лексике) внизу справа кнопка «В словарь» — список слов с галочками по группам. Её добавляет `js/bridge.js`: слова берутся из `window.MIRAE_WORDS`, если материал объявил его сам, иначе из `SETS`, `LESSONS`, `WORDS`, пар «слово — перевод» в заданиях `match` из `EPS` или `ALL`. Отмеченные слова ждут в `kr_vinbox:<ученик>` и попадают в словарь, как только ученик откроет страницу сайта со словарём;
- под видео в уроке и в домашке: кнопка «Добавить в словарь» (слова урока и слова теста из домашки).

**Исправить написание слова.** У ученика — «Слова» → карандаш у слова → поле «Слово». У преподавателя — карточка ученика → «Словарь ученика» → «Все слова» → карандаш (слово, перевод, пример) и «Словари» → карточка слова базы школы. id карточки зависит от написания, поэтому карточка переезжает под новое написание, а расписание, звёздочка и заметка сохраняются. Для правок преподавателя выполните в Supabase `supabase/vocab-rename.sql` (функции `teacher_vocab_edit` и обновлённая `teacher_word_save`: исправленное слово базы школы исправляется и у всех учеников). Без файла преподаватель может менять перевод и пример, но не написание.

**Скачать или скопировать список.** «Слова» → над списком «Скачать или скопировать» (по текущему фильтру), в кабинете — в карточке «Слова», у преподавателя — в «Словаре ученика». Форматы: «слово — перевод» (можно с примерами), Quizlet / Anki (слово, Tab, перевод) и таблица CSV для Excel и Google Таблиц.

Если слово у ученика уже есть и его добавляют ещё раз (или отмечают звёздочкой), интервал делится пополам и слово встаёт в очередь на сегодня.

**Отработка влияет на интервалы.** Ответы в упражнениях уроков и доп. упражнений (`lesson.html`) сами сдвигают слова ученика (`SRS.practice` в `js/srs.js`, `KR.vocab.practice` в `js/vocab.js`):

- ошибка: интервал слова делится пополам, слово приходит на повторение сегодня; у нового слова — первое место в очереди;
- верный ответ засчитывается как «Хорошо», только если слово и так пора повторять. Новое и изучаемое слово от верного ответа не меняется: его сначала проходят в тренажёре;
- одно слово сдвигается не чаще раза в день, а после ошибки верные ответы в этот день не засчитываются. Так исправить ответ и нажать «Проверить» ещё раз можно сколько угодно.

Под результатом упражнения ученик видит, какие слова вернулись на повторение и какие засчитаны. Преподаватель видит счётчик «ошибок в упражнениях» в блоке «Даются трудно».

Какое слово проверяет задание: явно — поле `w` у задания в данных урока (слово или список), иначе по правильному ответу (`KR.vocab.wordsIn`). Английские слова узнаются с простыми окончаниями (books, played, making). Корейские — в словарной форме, по основе из двух и более слогов и в частых формах глаголов на 하다. Основа из одного слога (가다) и основа, которая меняется при спряжении (마시다 → 마셔요), по ответу не узнаются: таким заданиям слово указывают в `w`. Тренажёры и тесты из папки `materials/` — отдельные страницы, на интервалы они пока не влияют.

Игры взяты из тренажёра группы 2724: карточки, выбор перевода на слух, слово в предложении, письмо, сборка слова из слогов, поиск пары. Ученик выбирает игры и меняет интервалы во вкладке «Настройки».

Чтобы словарь хранился в облаке и был виден преподавателю, выполните в Supabase файл `supabase/vocab.sql`. Без него словарь работает, но только на устройстве ученика.

### Словарь 2.0: база слов школы и словари преподавателя

Файл `supabase/vocab2.sql` (выполнить после `teachers.sql`) добавляет:

- **базу слов школы** — одна строка на значение слова: часть речи, значение (light «лёгкий» и light «светлый» — разные строки), уровень, переводы на русский и корейский, IPA британское и американское, примеры с переводами, объяснение, синонимы, картинка, темы. Отметка `sources` хранит, из какого словаря взято каждое поле;
- **словари преподавателя** — наборы слов с порядком, темой и уровнем. Словарь назначается ученику со сроком: его слова попадают в словарь ученика, сам словарь — в задания (материал `en-words-12`, `ko-words-7`);
- **копию слов ученика** с привязкой к базе: откуда слово, «сложное», личная заметка.

Страница «Слова» по-прежнему хранит слова и расписание в таблице `vocab`, а копия в новых таблицах обновляется триггером. Ошибка в копии не мешает словарю ученика. Пока файл не выполнен, сайт работает как раньше: страница «Словари» подсказывает, что нужно сделать, а «Слова» показывают карточку из того, что есть у ученика.

Что видит ученик: по нажатию на слово — полная карточка с транскрипцией и кнопками британского и американского произношения, примерами, синонимами и темами; отметка «сложное» и своя заметка; фильтры по словарю, теме, уровню и части речи; блок «Словари от преподавателя» с прогрессом и кнопкой «Учить первыми».

Как слова попадают в словарь преподавателя (страница «Словари», блок «Добавить слова»):

- **Поиск** — найти слово в базе школы или завести новое;
- **Из словаря** — взять слова другого словаря того же языка: все или только отмеченные галочками;
- **Импорт** — вставить список из Quizlet (в Quizlet: «⋯ → Экспорт», между термином и определением Tab), два столбца из таблицы или текст «слово — перевод | пример | перевод примера». Сайт показывает список с галочками: что новое, что уже есть в базе школы, что уже в словаре, где ошибка. Если перевод стоит слева, слово и перевод меняются местами. Новым словам заводится карточка в базе школы, слову из базы без перевода перевод дописывается. Разбор текста — `KR.W2.parseList` в `js/words2.js`.

Назначить ученику можно весь словарь или отмеченные слова («Какие слова» на странице «Словари» и в карточке ученика). Часть слов назначает функция `teacher_set_assign_words` из того же `supabase/vocab2.sql`; пока её нет на сервере, сайт назначает только словарь целиком и подсказывает, что обновить. Прогресс «выучено 3 из 5» у ученика считается по тем словам словаря, которые у него есть.

Словарные источники — Cambridge (английский) и NAVER (корейский) — подключатся сменными адаптерами после получения лицензий; до тех пор карточки заполняет преподаватель. Условия и план — в документе архитектуры Vocabulary 2.0.

### Тренажёры, тест и учитель в одном расписании

Расписание остаётся как в Anki (`js/srs.js`), а тренажёры, тесты и учитель его сдвигают:

- **Тренировка по выбору** (в «Отработке» на странице «Слова»). Ученик отмечает, какие слова гонять в тренажёрах: «На сегодня», «На завтра», «Ближайшие 3 дня», «На неделю», «Трудные» (забывалось, были ошибки, возвращал учитель, звёздочка), «Все слова»; можно несколько. Выбор хранится в настройках (`scope`) и синхронизируется. «Упражнения» — те же игры, что в отработке, «На слух» — тренировка на слух по этим словам. Слово, которое пора повторять, получает обычную оценку. Слово «на потом» от верного ответа не меняется, а от ошибки возвращается раньше: интервал вдвое короче, повторение — сегодня (`SRS.train`). Ошибка в тренировке ставит слово в конец круга ещё раз.
- **После сокращения** интервал растёт мягко: следующее «Хорошо» умножает его на 1,5, а не на «лёгкость» (поле `sh`). Так ошибка не превращается в длинный интервал сразу после повторения.
- **Тест «с учителем»** (`test.html?mode=class`, собранный в карточке ученика): под каждым ответом выбор «Вернуть слово»: «авто» (ошибка сокращает интервал, верный ответ засчитывается, если слово пора повторять), «сегодня» (заново, как после «Снова») или «завтра». В конце теста расписание записывается в словарь ученика функцией `teacher_vocab_put` из `supabase/vocab.sql` — **выполните этот файл в Supabase заново**. Без неё тест работает, а в итоге написано, что расписание не записано.
- **Тест «самостоятельно»** и тест из домашки, как и раньше, сдвигают интервалы; в итоге теперь видно, сколько слов вернётся сегодня и сколько засчитано.
- **Карточка слова**: «Повторить раньше: Сегодня / Завтра» — ученик сам возвращает слово (`SRS.send`).

## Перевод по выделению

Сначала перевод ищется в словах уроков и в словаре ученика (у корейских слов узнаётся основа: 지내지요 → 지내다). Если слова там нет, сайт обращается к переводчику из `TRANSLATE` в `js/config.js`:

- `"mymemory"`: бесплатный машинный перевод, выделенный текст отправляется на api.mymemory.translated.net (так сейчас);
- адрес своей функции: если подключите другой переводчик;
- `false`: только свои слова.

## Озвучка

Сайт выбирает лучший голос, который есть на устройстве, отдельно для корейского и английского. Ученик может выбрать голос и скорость на странице «Слова» → «Настройки». Самые живые встроенные голоса у браузера Microsoft Edge и у Safari на iPhone.

Для английского ученик выбирает произношение: британское или американское. По нему подбирается и голос устройства, и облачный голос. В карточке слова у транскрипции есть отдельные кнопки британского и американского произношения.

**Подкаст из слов.** Кнопки «Подкаст на сегодня» (в блоке «Отработка») и «Подкаст из списка» (над словами) читают слова по очереди и оставляют паузу на ответ: ученик успевает вспомнить и сказать ответ вслух до того, как его назовёт диктор. Настройки во вкладке «Настройки» → «Подкаст», на этом устройстве: пауза 2–12 с или «жду нажатия» (кнопка «Дальше»), порядок «слово → перевод», «перевод → слово» или «только слово», пример в предложении с переводом, «повтори за диктором» (слово ещё раз и пауза), слово дважды, «сначала медленно». Пауза, «Следующее слово» и «Стоп» — под карточкой; пока идёт подкаст, экран не гаснет (Wake Lock).

## Слова на слух и вслух

Код — `js/ear.js` (без страницы и сети, проверяется в node), игры — в `words.html`.

- **Диктант по клеточкам** (`dict`): звучит слово или пример к нему, ученик вписывает его; в клеточке корейский слог или английская буква, пробелы и знаки уже стоят. Ошибки видны прямо в клеточках: что вписано и как правильно. Фраза и ещё не выученное слово звучат сначала медленно, потом в обычном темпе; кнопки «ещё раз» и «Медленно».
- **Что прозвучало** (`hear`): звучит слово, выбрать, как оно пишется, из четырёх похожих на слух (달 / 탈 / 딸, ship / chip). Похожие слова — из словаря ученика или придуманные заменой одного звука; звуки, которые на слух не различаются (ㅐ/ㅔ, патчхим ㄷ/ㅅ/ㅌ, согласная после патчхима), не меняются.
- **Скажи слово** (`say`): на экране перевод, ученик говорит слово в микрофон (распознавание речи браузера: Chrome, Edge, Safari). Две попытки; «почти» — когда распознано близко. Если микрофон запрещён, игра до перезагрузки страницы не предлагается, есть «Ответить текстом». Микрофон есть и у нового слова в карточке: проверить своё произношение без оценки.
- **Сколько слов** (`cnt`): только в тренировке на слух, без оценки слова.

Три первые игры входят в обычную отработку (их можно выключить в «Настройках» → «Игры»). Кнопка «Тренировка на слух» даёт отдельный раунд из 12 слов, которые уже в работе, только на слух и вслух; ответы сдвигают интервалы, как упражнения уроков (`KR.vocab.practice`). В конце — список ошибок и «Подкаст из ошибок».

### Облачные нейроголоса

Функция `supabase/functions/tts` озвучивает корейский и английский живыми нейроголосами. Озвучивает она только для вошедших учеников и преподавателей: логин и PIN проверяются в базе. Готовая фраза сохраняется в хранилище Supabase (закрытая корзина `tts` создаётся сама), поэтому повторная озвучка той же фразы провайдеру не оплачивается. Если облако не ответило, сайт 10 минут говорит голосом устройства; если функция ответила «не настроено» (ключей ещё нет), — до конца сеанса браузера.

Как включить:

1. Развернуть функцию без проверки JWT (вход проверяет она сама): `supabase functions deploy tts --no-verify-jwt`. В рабочем проекте уже развёрнута.
2. В Supabase → Edge Functions → Secrets добавить провайдера и его ключ:

| Провайдер | Секреты | Голоса по умолчанию (корейский · британский · американский) |
| --- | --- | --- |
| Azure | `TTS_PROVIDER=azure`, `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION` | ko-KR-SunHiNeural · en-GB-SoniaNeural · en-US-JennyNeural |
| Google | `TTS_PROVIDER=google`, `GOOGLE_TTS_API_KEY` | ko-KR-Neural2-A · en-GB-Neural2-A · en-US-Neural2-F |
| OpenAI или OpenAI-совместимый шлюз (например OmniRoute) | `TTS_PROVIDER=openai`, `OPENAI_API_KEY`, по желанию `OPENAI_BASE_URL` и `TTS_MODEL` | голос `coral`, акцент задаётся указанием модели |

Другой голос задаётся секретами `TTS_VOICE_KO`, `TTS_VOICE_EN_GB`, `TTS_VOICE_EN_US`.

3. В `js/config.js` вписать адрес: `TTS_URL: "https://<проект>.supabase.co/functions/v1/tts"`. Для рабочего проекта уже вписан: как только в секретах появится ключ, облачные голоса заработают без новой публикации сайта.

Ключи провайдера живут только в секретах Supabase, на сайт они не попадают.

## Как включить регистрацию учеников

Сейчас учеников создаёт преподаватель. Чтобы ученики могли регистрироваться сами:

1. В Supabase откройте SQL Editor, вставьте содержимое `supabase/registration.sql` и нажмите Run. Запускать повторно безопасно.
2. Войдите на сайт как преподаватель, откройте «Ученики» и в карточке «Регистрация учеников» выберите режим:
   - **Закрыта**: как раньше, учеников создаёт только преподаватель.
   - **По коду школы**: ученик сам придумывает логин и PIN, но должен знать код. Код можно придумать кнопкой.
   - **Открыта**: зарегистрироваться может любой, у кого есть ссылка. Не больше 40 регистраций в сутки.
3. На странице входа появится вкладка «Регистрация». Новый ученик виден в списке с пометкой «новый», пока ему ничего не назначено.

Преподаватель может удалить ученика (вместе с прогрессом и назначениями) кнопкой «Удалить» в его карточке.

## Преподаватели

Владелец школы — тот, кто был преподавателем до файла `supabase/teachers.sql`. Он видит всех учеников и управляет преподавателями. Каждый преподаватель видит только своих учеников: тех, кого создал сам или кого ему передал владелец. Ученики, которые были в школе до этого шага, остаются у владельца.

Как включить: выполнить в Supabase файл `supabase/teachers.sql` (SQL Editor → New query → вставить → Run). Файл только добавляет: таблицы и данные не удаляются, запускать повторно безопасно. Пока файл не выполнен, сайт работает по-старому: единственный преподаватель считается владельцем.

Как появляются преподаватели:

1. **Владелец добавляет сам.** Панель «Ученики» → карточка «Преподаватели» → email и логин → «Создать». Сайт покажет сообщение с логином и PIN, его нужно переслать преподавателю.
2. **Заявка по коду.** Владелец задаёт код преподавателя в той же карточке. Человек с кодом открывает страницу входа → «Регистрация» → «Я преподаватель» (прямая ссылка: `auth.html#teacher`). Заявка появляется у владельца, доступ к ученикам открывается после «Подтвердить». Пустой код выключает заявки.

В карточке ученика владелец выбирает, кто его ведёт («Ведёт»). Снятие роли возвращает учеников этого преподавателя владельцу. Настройки регистрации учеников и код школы меняет только владелец.

## Прохождение как история

Страница курса уже показывает программу как путь: пройденные главы, текущая, закрытые и будущие, золотая линия доходит до текущей главы.

Чтобы добавить главе сюжетную вставку, допишите уроку в `data/course.js` поле `scene`:

```js
{ no: 12, title: "-지요?", id: "l12-jiyo", scene: "Короткий текст сцены" }
```

Текст появится в карточке главы. Состояние ученика хранится в Supabase одним объектом; незнакомые ключи при сохранении не теряются, так что будущие данные сюжета (выборы, открытые сцены) можно класть рядом с `progress`.

## Помощник

В `js/config.js` есть переключатель `ASSISTANT`:

- `false`: выключен;
- `"teacher"`: кнопку и панель видит только преподаватель (так сейчас);

## Библиотека упражнений и уроков

Страница `library.html` (в шапке у преподавателя — «Библиотека»), код — `js/library.js` (`KR.lib`), база — `supabase/library.sql`.

- **Блоки.** Каждое упражнение и каждый блок теории — отдельная запись: блок в том же виде, что в `data/*.js`, плюс язык, уровень, тема, теги и источник (`l12-jiyo/practice-0`). Кнопка «Собрать из уроков сайта» кладёт в библиотеку блоки всех уроков, загруженных на странице. Уровень берётся из подписи курса (`1급 · 12과` → 1급, `CLT-синтез · A1` → A1, хангыль → A0), тема — из названия урока. Повторный сбор обновляет сам блок, а уровень, тему и теги, которые поменял преподаватель, не трогает.
- **Поиск и фильтры:** текст (ищет и внутри заданий), язык, уровень, тема, тип блока, ♡ избранное (у каждого преподавателя своё). Карандаш — тема, теги и уровень блока.
- **Свой урок.** Отметить блоки галочками → «Собрать урок»: теория идёт в раздел «Теория», упражнения — в «Отработку». Урок хранит ссылки на блоки, а не копии: исправленный блок обновится во всех уроках. Выбранные блоки можно добавить и в уже собранный урок.
- **Урок из библиотеки** открывается как `lesson.html?l=lib-<номер>` (вкладка «Мои уроки» → «Открыть») и задаётся домашкой кнопкой «Задать ученику»: в домашку уходит `{"l":"lib-<номер>","b":[…]}`, как у уроков сайта. Ученик открывает такой урок только из своей домашки (`lib_lesson_get` проверяет это на сервере).
- **Права.** Искать, отмечать ♡ и менять теги может любой преподаватель. Менять сам блок и удалять блоки и уроки — автор или владелец школы.

Чтобы включить, выполните в Supabase `supabase/library.sql` (после `homework.sql`). Пока файла нет, страница подсказывает, что сделать.

- **Правка урока** («Мои уроки» → «Изменить»): название, подзаголовок, названия разделов и часть (теория / отработка), порядок блоков ↑↓, убрать блок из урока. Блоки, удалённые из библиотеки, видны с пометкой и при сохранении выпадают. Названия блоков в редакторе берёт `teacher_lib_get` из `supabase/library2.sql`; без него редактор показывает их по уроку.
- **Уроки из библиотеки везде, где уроки сайта:** панель преподавателя («Задать домашку» по блокам и отдельным заданиям, прогресс, слова урока), группы и тест по словам урока (`test.html?l=lib-<номер>`). Страницы загружают их через `KR.lib.loadAll()` / `KR.lib.ensure()`.
- Типы блоков в фильтре и предпросмотре: и новые `match`, `order`, `write`, `speak`, `video`.

## Группы

Страница `groups.html` (вкладка «Группы» рядом с «Ученики» и «Словари»), код — `js/groups.js`, база — `supabase/groups.sql`.

Группа — это список учеников. Всё, что преподаватель делает с группой, раскладывается на каждого ученика прежними функциями (`teacher_assign`, `teacher_set_assign`, `teacher_vocab_add`, `teacher_hw_save`). Поэтому уроки, слова и домашка у ученика лежат там же, где и на индивидуальных занятиях, а в базе группы хранятся только состав, программа и журнал занятий.

- **Группа:** название, язык, ученики («Состав и название»). Новый ученик сразу получает открытые уроки программы и словари группы, прошлую домашку — нет. Ученик, который ушёл из группы, сохраняет свои уроки и слова. Владелец школы видит все группы.
- **Программа группы:** уроки и материалы каталога по порядку, у каждого статус «открыт», «закрыт» или «на занятии <дата>». Открыть урок — значит назначить его всем ученикам группы (у кого он уже назначен лично, срок и комментарий не меняются). Галочка «Открывать уроки по мере занятий»: новый урок программы открывается, когда группа до него дошла. Без неё урок открывается сразу.
- **Словари группы:** весь словарь или отмеченные слова назначаются каждому ученику и потом новым ученикам тоже.
- **«Пройден на занятии»:** дата, урок (по умолчанию — первый непройденный урок программы) и присутствие: «Был», «Опоздал», «Не был». После записи:
  - урок открыт всем ученикам группы;
  - слова урока (галочка) уходят в словарь всем ученикам как новые;
  - тем, кого не было (галочка), уходит домашка «Догнать урок»: задания с занятия (отработка или ступень «на занятии») и ссылка на теорию;
  - следующий урок программы (галочка, по умолчанию как в «Открывать по мере занятий») открывается всем.
- **Посещаемость:** таблица «ученик × последние 8 занятий» (✓ был, ⏱ опоздал, ✗ не был) и «был N из M». Журнал занятий внизу, запись можно удалить: уроки, слова и домашка учеников при этом остаются. В карточке ученика на странице «Ученики» — блок «Группы»: сколько занятий был и какие уроки пропустил.
- **Ученик** на странице курса видит урок, пройденный с ним на занятии, как пройденный («пройден на занятии <дата>»), а пропущенный — со значком «Догнать», пока не пройдёт его сам (`my_group_sessions`).

### Домашка и тесты группе

- **Задать группе.** «Группы» → «Задать домашку группе» или «Тест по словам группе» открывают карточку первого ученика группы на странице «Ученики» с уже выбранной группой. В конструкторе домашки и в «Тесте и отработке слов» есть поле «Кому»: только этому ученику или его группе, с галочками учеников. Конструктор тот же: упражнения целиком или отдельные задания, тренажёры, теория, срок.
- **Тест группе:** «У каждого свои слова» — каждому собирается тест по тем же правилам (источники, микс, форматы, число вопросов) из его собственного словаря; кому не хватило двух слов, тест не задаётся (сайт называет таких учеников). «Одинаковые для всех» — всем слова из подсказки. «Слова урока» у всех одинаковые.
- **Как хранится:** каждому ученику — обычная домашка (`homework`) с меткой группы `grp` и выдачи `batch` (`teacher_group_hw_save`). Ученик сдаёт её как обычно.
- **Сводная таблица** на странице «Группы»: ученики × последние 6 выдач — «задано», «просрочено», «сдано 75%», «✓ 75%» (проверено).
- **Ошибки выдачи:** общие (одинаковый вопрос у двоих и больше) и остальные, с ответами каждого. «Разобрать на уроке» показывает общие ошибки списком, верный ответ открывается по нажатию. «Работа над ошибками» задаёт каждому сдавшему домашку только из тех вопросов упражнений и слов теста, где ошибся он сам (тренажёры сюда не входят). «Убрать у тех, кто не сдал» снимает выдачу с несдавших.

Чтобы включить, выполните в Supabase `supabase/groups.sql` (после `teachers.sql` и `homework.sql`; после обновлений файла — ещё раз). Пока файла нет, страница подсказывает, что сделать, а остальной сайт работает как раньше.

## Курс «Хангыль с нуля»

Десять занятий по методическому маршруту HANGUL FROM ZERO лежат в `data/hangul.js` и идут на странице курса первой частью «한글». Ученик видит её, когда ему назначено хотя бы одно занятие.

Кроме обычных блоков в этих уроках есть два новых:

- `choice` с полем `say`: вместо текста звучит слог, ученик выбирает услышанное. Поле `opts` задаёт варианты для конкретного вопроса.
- `build`: ученик собирает слог или слово, нажимая буквы (`keys`). Буквы сами складываются в блоки: ㄱ ㅏ ㄴ → 간, ㅗ + ㅏ → ㅘ.

Чтобы занятия можно было назначать, один раз выполните в Supabase `supabase/add-hangul.sql`.

## Значения слова и режим отработки

`js/meaning.js` (KR.mean, без страницы и сети, проверяется в node). У слова в словаре ученика может быть несколько переводов
(`t`, через «;»), определения и переводы на любых языках (`d: [{l, s}]`, язык по буквам или «de: …»), синонимы (`syn`)
и устойчивые выражения (`col: [{s, t}]`). Всё это редактируется в списке слов (карандаш); в форме «Добавить слово» и в списке
слов русское идёт в переводы, остальное — в определения.

Проверка не считает ошибкой синоним, другое слово с тем же переводом или любое из значений («Напиши слово», «Скажи слово»,
новая игра «Что значит»). Ответ, которого нет в словаре, ученик может засчитать сам — он добавится к значениям слова.
Слова с общим значением не ставятся вариантами в одно задание и в одну «Найди пару».

Режим отработки (Настройки, для каждого языка отдельно, `settings.ctxm`): «В контексте» — задания только на изучаемом языке
(определение, устойчивое выражение или пример с пропуском, синонимы; рекомендуем с 2급 / A2), «С русским», «Вперемешку».

## Словарь: определения, примеры, синонимы

Функция `supabase/functions/dict-lookup` (вход по PIN, как у `translate-words`):
- корейский — 한국어기초사전 (Национальный институт корейского языка, Open API, CC BY-SA 2.0 KR): определение по-корейски,
  переводы и определения по-английски и по-русски, уровень, примеры, устойчивые выражения (구), синонимы. Нужен бесплатный
  ключ: зарегистрироваться на https://krdict.korean.go.kr/openApi/openApiInfo, ключ — в секрет функции `KRDICT_KEY`.
  Без ключа корейские слова ищутся в Викисловаре (только английские значения);
- английский — Free Dictionary API (dictionaryapi.dev, данные Викисловаря, CC BY-SA), запасной — Викисловарь.

Cambridge и NAVER открытого API не дают; когда будут лицензии, они подключаются отдельными адаптерами в той же функции.

На странице «Слова»: статья подтягивается сама при знакомстве с новым словом, по кнопке «Из словаря» в карточке слова,
«Заполнить из словаря» в форме правки (поля заполняются, сохраняет ученик) и для всех слов раздела без статьи (до 40 за раз).
В карточку добавляется только то, чего в ней ещё нет; источник пишется в карточке слова.

**Значения слова.** `dict-lookup` отдаёт значения по отдельности (`senses`: переводы, определения, примеры, выражения,
синонимы каждого значения; у корейских слов — до трёх омонимов). В карточку и в отработку «в контексте» попадает только то
значение, которое ученик учит: оно подбирается по переводу в карточке (у 까먹다 «забывать» — значение «잊어버리다», а не
«чистить и есть»), а в карточке слова («Какое значение учу») его можно выбрать вручную (`sn`). Карточки, заполненные раньше
из всех значений подряд, страница «Слова» поправляет сама в фоне (`KR.dict.refit`, до 40 слов за открытие; поправленные — `sv: 2`).

**Уровень.** Примеры, определения и выражения в контексте подбираются по уровню ученика, а не слова (`KR.mean.level`,
`KR.mean.fits`): по длине — слоги и слова для корейского, слова для английского. Уровень — Настройки → «Мой уровень»
(`lv` в настройках), иначе подбирается по числу слов в словаре. Словарный пример не по уровню из карточки убирается;
свой пример ученика или преподавателя остаётся. После изменения функции её нужно развернуть заново:
`supabase functions deploy dict-lookup --no-verify-jwt` (пока она старая, сайт работает как раньше).

Порядок перевода везде один — база слов школы → словарь → DeepL (функция `translate-words` вызывает `dict-lookup` пакетом):
список слов на странице «Слова» и выделение в уроке (`js/lookup.js`, слово или фраза до 4 слов у вошедшего ученика; длиннее —
MyMemory, как раньше). Если в словаре нет русского перевода (у английских слов Free Dictionary даёт только английские определения),
русский перевод даёт DeepL, а определения и примеры всё равно берутся из словаря (пометка «словарь + DeepL»). С выделенным словом в словарь ученика уходит и статья словаря.
Общий код клиента — `js/dict.js` (KR.dict).

Записи произношения из словаря: `dict-lookup` возвращает `audio` (английский — британская и американская записи Free Dictionary,
корейский — запись 한국어기초사전, если словарь её даёт), они сохраняются в карточке слова (`au`). `KR.say` (js/common.js)
для отдельного слова сначала спрашивает `KR.rec` (js/dict.js) и играет запись диктора; нет записи или она не загрузилась —
облачный голос или голос устройства, как раньше. Фразы и примеры по-прежнему озвучивает синтез.

## Видео в уроках · общий плеер (`js/player.js`)

Один плеер для всех материалов с видео (сейчас: `ko-suchwita`, `ko-skz-holiday`). Подключение — после моста:
`<script src="../../../js/player.js"></script>`, вывод — `MIRAE_PLAYER.html({...})` или `MIRAE_PLAYER.mount(el, {...})`.

- `file` — свой ролик сайта из `media/video/` (короткое имя файла). Открывается в России без VPN, показывается первым.
- `alt` — VK Видео / Rutube (адрес `src` из кода для вставки), `yt: {id, start, end}` — YouTube; остальные плееры — кнопками под видео.
- `cover: true` — кнопка «Скрыть субтитры» (полоса поверх вшитых субтитров; можно `{bottom: 7, height: 19}` в % кадра).
- `time`, `hint` — подпись под плеером.

Как добавить отрывок: вырезать из выпуска и сжать (H.264 + AAC, быстрый старт), положить в `media/video/`:
`ffmpeg -ss 863 -to 1200 -i episode.mp4 -c:v libx264 -preset veryfast -crf 25 -c:a aac -b:a 96k -movflags +faststart media/video/имя.mp4`.
Держите отрывки короткими (до ~20 МБ): GitHub не принимает файлы больше 100 МБ.

### Урок со ступенями: теория → на занятии → домашнее задание

Если у урока `"stages": true`, он показывается одной лентой без вкладок «Теория/Отработка», а внутри каждого раздела
блоки идут ступенями: без поля `at` — теория, `"at":"class"` — на занятии, `"at":"home"` — домашнее задание.
Перед первой карточкой каждой ступени — подзаголовок. Пример — `data/sw5-l4.js`.

### Новые блоки уроков: `match`, `order`, `write`, `speak`

- `match` — сопоставление (оба столбца по-корейски): `items: [{l, r}]`, проверка кнопкой «Проверить».
- `order` — собрать предложение из частей: `items: [{w: [части], a: [верные варианты], p?}]`.
- `write` — письменный ответ: `prompts`, `model` (образцы, открываются после «Сохранить ответы»), `rows`. Ответы уходят преподавателю в домашке.
- `speak` — чтение вслух с проверкой произношения (`js/ear.js`, как в «Словах»): `lines: [[кто, текст]]`, `roles` — выбор роли.

Панель преподавателя: у урока со ступенями в «Задать домашку» задания сгруппированы по разделам с пометками «на занятии / на дом»
и кнопкой «отметить всё «на дом»»; галочки «Внести слова урока в словарь ученика» есть в «Задать домашку» и в «Назначить материалы».
